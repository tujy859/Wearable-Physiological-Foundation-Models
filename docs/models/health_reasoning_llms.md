# 可穿戴健康推理与生理大语言模型

随着智能手表、连续血糖仪（CGM）等消费级与临床设备的普及，个人健康时序正从孤立的瞬时生理读数演化为长程纵向健康轨迹。传统的生理基础模型主要聚焦于高频物理波形的表征压缩与单点预测；而面对病理因果归因、多模态联动分析与生活干预建议的诉求，研究方向逐渐由底层信号表征拓展至健康认知推理。

本专题梳理健康推理基准（WearableQA、HEARTS）、典型跨模态对齐与微调模型（CBPM-LLaMA、GEM），并分析“底层专用生理基座 + 中层工具调度 + 顶层推理 Agent”的分层分工体系。

## 1. 从信号表征到健康认知推理

以往可穿戴生理信号模型主要遵循单点预测与表征学习范式：
- **任务形式**：输入长为 $T$ 的生理信号片段，预测下一时刻的数值 $X_{t+1}$（回归），或判别当前片段是否属于某一特定病理类别（如房颤、睡眠呼吸暂停）。
- **评测指标**：均方根误差（RMSE）、平均绝对误差（MAE）、分类准确率与 F1 分数。

在实际健康管理场景中，用户与临床人员常需要具备医学解释性与因果链条的综合分析，例如：
> “为什么昨晚静息心率升高了 10 bpm，且深睡减少了 40 分钟？”

解答该问题通常需要跨模态、跨尺度的联合分析：
1. **多指标协同分析**：结合白天的活动量、运动强度与饮食记录综合研判；
2. **长程个体基线比对**：与过去数周的个人昼夜节律基线相比，判断波动是否偏离正常范围；
3. **可能原因排查**：分析属于高负荷运动后的生理恢复、交感神经兴奋还是偶发环境影响；
4. **行动建议**：评估是否需要调整后续训练强度、补充水分或持续观察体温变化。

底层物理信号模型负责提取生理表征，而健康推理系统则在表征与医学先验之间建立因果推导与决策支持桥梁。

## 2. 大语言模型直接处理高频连续波形的瓶颈

部分研究曾尝试将连续物理信号直接数值序列化（如转为字符串文本）输入通用大语言模型进行端到端建模。在可穿戴高频生理信号场景下，该做法存在以下瓶颈：

1. **Token 序列过长与计算开销**：
   - 智能手表原始 PPG 采样率通常为 25～100 Hz，单导联 ECG 达到 250～1000 Hz。
   - 100 Hz 单通道信号持续采集 1 小时即产生 360,000 个浮点采样点；全天采集产生近 1000 万点。直接转换为文本格式输入将带来严重的上下文长度与计算成本开销。
2. **分词算法对数值几何关系的破坏**：
   - 通用 LLM 采用的 BPE / SentencePiece 分词基于子词频次统计。
   - 面对连续浮点数（如 `128.45` 与 `128.49`），分词器容易将其拆解为不规则的片段，破坏了实数的连续距离拓扑与物理量纲，易引发数值幻觉。
3. **局部归纳偏置缺失**：
   - 生理波形分析依赖局部形态特征、周期性与频域先验（如利用加速度计抑制手腕 PPG 运动伪影、利用微秒级间期诊断心电传导阻滞）。标准的全局注意力机制缺乏频域滤波或状态空间方程等归纳偏置。
4. **启发式捷径倾向**：
   - 在高频连续时序直接生成评测中，纯语言模型容易出现复制临近周期波形或简单线性插值等现象，对于微观高频形态的建模鲁棒性相对较弱。

## 3. 经典模型与评测基准

### WearableQA

Meta AI / Reality Labs · 2026 · [论文](https://arxiv.org/abs/2609.05405)

![WearableQA 数据构建与题型设计](../figures/wearableqa/overview.png)

图源：WearableQA 论文 Fig. 1（arXiv:2609.05405）

WearableQA 是面向真实世界长程可穿戴数据构建的健康推理基准，旨在评估大语言模型在长期生理监测与生活方式推理中的表现。

**数据集画像**

- 涵盖 200 名真实用户长达 500 天的连续记录，包含 16 维每日心肺、运动与睡眠聚合指标。
- 结合 17 项临床实验室血液生化化验面板与大样本群体分位数先验。
- 共构建 4,084 道 10 选 1 多项选择推理题。

**评测体系**

- **解耦评测**：严密分离纯数据计算推理（Data Reasoning，如时序趋势统计、极值定位）与健康机制推理（Health Reasoning，如疾病风险评估、生理机制解释）。
- **双重真实标签锚定**：采用顶级医学指南与统计显著性（$p < 0.001$）双重锚定答案。

**评测发现**

- 主流大模型（如 Gemini、GPT 系列）在长程连续数字计算与微弱生理异常捕捉上仍存在提升空间，中小开源模型在无外部工具辅助时的准确率明显受限。

### HEARTS

Yang AI Lab · ICML 2026 · [论文](https://arxiv.org/abs/2603.06638) · [代码](https://github.com/yang-ai-lab/HEARTS) · [主页](https://yang-ai-lab.github.io/HEARTS/)

![HEARTS 四层认知阶梯与任务图谱](../figures/hearts/overview.png)

图源：HEARTS 论文 Fig. 1（ICML 2026）

HEARTS（Hierarchical Evaluation of Biosignal Foundation Models）构建了覆盖全谱系健康时序的基础模型与大语言模型评测体系。

**基准构成**

- 整合 16 个开源数据集、12 个健康领域、20 种生理模态（ECG、EEG、PPG、EMG、CGM、呼吸音等），采样率跨越每日聚合到 48 kHz。
- 涵盖 110 项任务与 20,226 个评测样本。

**四层认知能力阶梯**

1. **Perception（底层感知）**：信号滤波、重构与质量评估；
2. **Inference（状态推断）**：疾病诊断与生理状态分类；
3. **Generation（波形生成）**：跨模态合成与缺失值插补；
4. **Deduction（纵向因果演化）**：健康轨迹反事实推演与因果归因。

**核心结论**

- 在高频连续时序任务中，专用轻量时序基础模型（如 PaPaGei、MOMENT）的特征质量具有优势；
- 大语言模型借助 CodeAct 范式调用专业科学计算库（SciPy、NeuroKit2），可显著降低数值幻觉并提升推理准确度。

### CBPM-LLaMA

中科院深圳先进技术研究院 / 香港理工大学 · ACM-BCB '24 · [论文](https://arxiv.org/abs/2406.18069) · [代码](https://github.com/zdzdliu/CAS-BP)

![CBPM-LLaMA 框架结构图](../figures/cbpm-llama/overview.png)

图源：CBPM-LLaMA 论文 Fig. 1（ACM-BCB '24）

CBPM-LLaMA（Cuffless Blood Pressure Measurement via LLMs）探索将心血管血流动力学先验引入大语言模型微调，用于可穿戴无袖带连续血压估计。

**方法**

- **血流动力学先验解耦**：从 1000 Hz 同步 ECG 与 PPG 中提取 31 维特征，依据生理学原理归入心输出量（CO）、外周阻力（PR）和大动脉硬度（PTT）三类。
- **目标重构与反解**：提示词引导大模型分别预测平均动脉压（MAP，主要由 CO 与 PR 决定）和脉压差（PP，反映大动脉硬度与顺应性）：

  $$
  \text{MAP} \approx \frac{1}{3}\text{SBP} + \frac{2}{3}\text{DBP}, \quad \text{PP} = \text{SBP} - \text{DBP}
  $$

  再通过代数公式反解收缩压与舒张压：

  $$
  \text{SBP} = \text{MAP} + \frac{2}{3}\text{PP}, \quad \text{DBP} = \text{MAP} - \frac{1}{3}\text{PP}
  $$

- **模型微调**：基于 LLaMA-Factory 框架对 LLaMA-3-8B 等模型进行指令微调。训练时输入用户画像与机制特征，仅对输出数值计算自回归损失。

**结果与评估机制分析**

- 在包含 1,272 名受试者的 CAS-BP 队列中，引入血流动力学解耦 Prompt 使收缩压（SBP）未校准平均绝对误差由 7.77 mmHg 降至 7.08 mmHg。
- 论文在测试阶段引入了静态基线校准：

  $$
  \text{SBP}_{\text{cal}} = 0.3 \times \text{SBP}_{\text{free}} + 0.7 \times \text{BaseSBP}
  $$

  需注意该步骤依赖受试者首日的袖带基线真值。若剥离该校准，纯模型输出的 SBP MAE 约为 7～8 mmHg。
- 该解耦思路对轻量级传统模型（XGBoost、1D-CNN）同样适用，可作为低成本的生理归纳偏置。

### GEM

北京大学 / 新加坡国立大学 · NeurIPS 2025 · [论文](https://arxiv.org/abs/2503.06073) · [代码](https://github.com/lanxiang1017/GEM)

![GEM 双编码器架构图](../figures/gem/overview.png)

图源：GEM 论文 Fig. 2（NeurIPS 2025）

GEM（Grounded ECG Multimodal Large Language Model）针对医疗多模态大模型在心电解读中缺乏因果链条与证据锚定的问题，提出了波形物理锚定范式（ECG-Grounding）。

**方法**

- **时序与视觉双编码器**：融合 1D 原始高频心电时序编码器（感知毫秒级波形形态）与 2D 临床心电打印图纸视觉编码器（对齐临床阅片习惯）。
- **微观波形参数物理锚定**：在输出诊断结论前，强制要求模型测量并输出可客观验证的生理参数（如 PR 间期、QRS 宽度、QT/QTc 间期、ST 段抬高或压低毫米数及其对应的具体导联）。
- **指南逻辑绑定**：将测量参数与临床诊疗指南阈值绑定，提供完整的证据链支持。

**结果**

- 在心血管疾病诊断测试中，相比无物理锚定的常规基线，GEM 在诊断准确率上提升 7.4%，病理依据锚定准确率提升 25.3%，降低了无依据幻觉输出的发生率。

## 4. 三层分工架构：生理感知、神经符号与健康 Agent

可穿戴生理信号基础模型与大语言模型的融合呈现出分层协同的技术架构：

![三层分工技术架构图](../figures/health_reasoning/hierarchical_ai_stack.png)

图源：依据多模态生理健康系统架构绘制

1. **底层 · 微观高频物理感知与生理基座（Edge Sensor FMs）**：
   - 运行于智能手表或轻量贴片端侧，参数量通常在数兆以内（如 PaPaGei、HiMAE、GlucoFM）。
   - 负责高频去噪、运动伪影抑制并提取紧凑的生理潜表征，将原始密集采样流压缩为结构化指标。
2. **中层 · 神经符号与工具调度执行层（Neuro-Symbolic & CodeAct）**：
   - 基于 Python 运行时调度专业信号处理库（SciPy、NeuroKit2、BioSPPy）。
   - 执行精确的数值积分、显著性检验与频域谱分析，避免语言模型直接进行浮点数学运算带来的数值幻觉。
3. **顶层 · 认知与健康决策中枢（Cognitive & Reasoning Layer）**：
   - 接收中层与底层沉淀下的结构化生理指标，结合电子病历、生化化验与临床指南，生成具备因果链条的分析与建议。

## 5. 路线对比：模块化 Agent 与原生多模态融合

在时序信号与自然语言结合的研究中，主要存在两种技术分支：

| 路线分支 | 代表工作 | 核心机制 | 适用场景与权衡 |
| :--- | :--- | :--- | :--- |
| **模块化 Agent 架构** | WearableQA, HEARTS (CodeAct) | 端侧基模提取特征 → 中层工具精确数值计算 → 顶层 LLM 因果推理 | 计算精确、循证依据明确、适合长程纵向慢病健康管理；链路相对较长。 |
| **原生多模态交错融合** | SensorLM, PPG-LM, TimeBraid | 统一 Transformer 架构中交织时序 Patch 与语言 Token，原生跨模态对齐 | 支持端到端波形检索、语义问答与反事实（What-If）推演；对配对预训练数据与对齐方案要求较高。 |
